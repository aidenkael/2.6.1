# UI 结构说明（UI_STRUCTURE.md）

> 基于 `original/main-ui-original.svg` + `main-ui-preview.png` 与 `original/settings-ui-original.svg` + `settings-ui-preview.png` 整理。

## 共同结构（两个屏幕共享）

画布尺寸：1920 × 1080。整体采用三段式布局：左侧导航栏 + 顶部状态条 + 主内容区。

### 1. 左侧导航栏（Sidebar）

- **位置**：左侧 280 px 宽区域（从 x=0 至 x=280），垂直贯穿整个屏幕。
- **背景**：`#F8FAFD`，与主内容区以 1px `#EAF0F6` 分隔线区分。
- **顶部 Logo 块**：44×44 圆角蓝色方块 `#1769F6`，内嵌应用图标（白色）。右侧显示应用名称与版本号。
- **导航项列表**（从上到下），高度约 48 px，图标在左、文字在右：
  - `以图搜图`
  - `新商品测算`（主界面为当前页，此项高亮显示）
  - `历史记录管理`
  - `数据导入导出`
  - `模型校准反馈`
  - `设置`（设置界面为当前页，此项高亮显示）
- **底部信息块**：左下角约 232×103 卡片，含：
  - 「数据目录」标签 + 路径 `C:\ProfitManager\data`
  - 「更改目录」按钮
  - 下方一个独立小卡片（232×107）：「USD → RMB 汇率」标签、当前数值（主界面：7.20，设置界面：7.20）、刷新按钮、`更新时间` 行、`当前版本` 行
- **页脚**：最底部左侧一行小字 `当前版本: 1.5.0`。

### 2. 顶部状态条（Top Bar）

- **位置**：从 y=0 至 y=72，宽度 1920 px；与下方主内容区以 1px `#EAF0F6` 分隔。
- **左侧**：屏幕标题（大字）与副标题（灰色小字）。
  - 主界面：`新商品测算` + `图片识别、快速选品与利润测算在同一页面完成`
  - 设置界面：`设置` + `汇率、货代、利润规则的统一管理`
- **右侧**：
  - 「未保存」状态徽章（橙色背景 `#FFF4E5`）
  - 用户头像圆形（`#1769F6` 蓝底，白色字母 "A"）+ 用户名 `张三`

## 主界面（main-ui）

主内容区从 (280, 72) 起，宽度 1640 px，高度 1008 px，背景 `#F5F8FC`。

### A. 图片输入区

- 卡片容器，白底圆角 12，1px `#DCE5F0` 描边，从 (296, 88) 起，宽 1607，高 285。
- 标题：`图片输入`（左） + 副标题 `到认图、变物上传、变图、Ctrl+V、提取和删除`（灰色小字）+ 右侧 `5 +` 与 `保存图片配置`、`AI 提图` 按钮。
- **5 个图片上传框**（`主图`, `商品信息`, `尺寸/重量`, `商品信息`, `尺寸/重量`），每个高 217 px。
  - 顶部下拉选择框（`主图`/`商品信息`/`尺寸/重量`）。

## 待确认事项汇总

下列内容从截图与 SVG 中均无法 100% 确认，建议在下一次沟通中补充或反查原设计稿：

1. **货币名称输入框当前值**：视觉上接近「第五」，可能为「第伍」或代码片段；建议向设计/产品方核实。
2. **基础设置区第 4 个字段**：在预览图中位置与单位未明确识别。
3. **货代方案中具体数值**：金额、单价、换算系数较多，识别可能存在字符级误差（如 `¥40.00` 与 `¥10.00` 视觉相近）。
4. **利润测算「已提交」徽章数值**：右上角徽章文字颜色为浅绿，识别为「已提交 +$2.99」，需确认是否准确。
5. **未保存状态触发条件**：右上角「未保存」徽章的显示逻辑（哪些字段变更后显示）。
6. **图标字形**：左侧导航栏与表头的所有图标为 SVG path 绘制，无标准图标库标识，建议在 UI 接入时按视觉意图自选图标库替换。
