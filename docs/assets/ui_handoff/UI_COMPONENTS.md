# UI 组件清单（UI_COMPONENTS.md）

> 基于两个屏幕的视觉检查 + SVG 结构识别整理。
> 字段含义：`位置` 是 SVG 内的近似坐标；`可见状态` 仅记录当前快照下的视觉状态；`大致用途` 不替代业务逻辑定义。

## 状态 / 类型补充

### 静态 vs 交互（推测）

下列交互类型未在 SVG 中体现，需根据业务规则补全：

- 导航项 hover / active 状态
- 按钮 hover / pressed / disabled 状态
- 输入框 focus / error 状态
- 下拉框展开状态
- 表格行 hover / selected 状态
- 卡片选中状态
- 「未保存」徽章的触发与消失

### 可编辑 vs 只读

| 类型 | 组件示例 |
|------|---------|
| 可编辑 | 输入框、下拉框、按钮 |
| 只读展示 | 总成本汇总卡、利润测算结果、规则列表徽章 |
