## 文字提取方法说明

1. **PNG 文字提取**：使用 `Read` 工具直接观察 `original/*.png`，人工辨识中文字符与数字。
2. **SVG 文字提取**：SVG 中 `<text>` 元素极少，绝大多数为 `<path>` 元素（字符轮廓被绘制为路径），因此无法直接读取 `<text>` 标签内容。
3. **识别难点**：
   - 中文字符在压缩预览图中可能模糊（特别是字号 < 14px 的说明性文字）
   - 数字 `0` 与字母 `O`、`1` 与 `l` 容易混淆
   - `5.00` 与 `5.0` 等尾随零在预览中显示模糊
   - 部分字符可能是「音近不同字」，需要原始设计稿二次核对

## 建议复核清单

下列文字建议在原始设计稿中复核：

- 主界面副标题（图片输入、AI 识别摘要、成本与规格、货代方案、利润测算）
- 字段标签（如 `唢寸/唢高/哋现`、`包袋尺す`、`物流+学成费`、`包袋+仓股费`）
- 顶部按钮 `5 +` 的真实意图
- 货代方案中大量 RMB/USD 数值
- 设置界面「货币名称」输入框当前值
- 设置界面第四个基础字段
- 利润调整规则列表中两条规则的副标题
- 计算规则说明文案
- 利润概要说明文案
