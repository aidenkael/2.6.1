# UI_DEVIATION_REGISTER

## 使用规则

任何 UI 控件的新增、删除、改名、合并、可编辑性改变、区域重排或功能改变，必须先登记并获得用户明确确认。未经确认的条目不得实施。

状态：

- `BASELINE_INTERPRETATION`：对预览图示例或文字的已确认解释，不是新增功能；
- `PENDING`：待用户确认；
- `APPROVED`：用户已明确同意；
- `REJECTED`：不得实施；
- `IMPLEMENTED`：已按确认实现并通过验收。
