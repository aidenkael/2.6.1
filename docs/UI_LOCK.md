# UI 锁定规范

权威顺序：

1. 用户最新修改意见
2. 1920×1080目标截图
3. SVG
4. 现有代码

固定验收环境：

- Windows 1920×1080
- 系统缩放100%
- 软件最大化
- 主页面最大化后没有滚动条，缩小后不压缩ui，出现滚动条

执行规则：

- 不重新设计，不自行美化，不调整已确认名称。
- 严格保持截图中的区域顺序、宽高比例、对齐、间距和颜色层级。
- 不使用Qt默认控件尺寸和默认边距。
- 所有控件必须显式设置尺寸、间距、边距和样式。
- 功能接入不得改变已锁定布局。
- 修改后必须生成实际运行截图，与目标图并排比较。
- 未达到视觉一致前，不得打包。
