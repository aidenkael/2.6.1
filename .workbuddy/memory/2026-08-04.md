### 踩坑记录（可复用）
- PySide6 QUiLoader 加载的 .ui 根节点若无 Python 引用会被 GC，后续操作报 `libshiboken: Internal C++ object already deleted`——测试夹具必须持引用
- 页面级 `capture_current_settings` 必须从 `settings_service.load()` 取最新值，不能用页面缓存的 `_exchange_rate`（否则重开后用户编辑仍用旧汇率）
- 加载记录填充控件时若不阻断信号，`setValue` 会触发编辑 handler → 提前 `_exit_snapshot_mode`，必须 QSignalBlocker 包裹全部可编辑控件
