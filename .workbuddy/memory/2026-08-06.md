## UI 模块化拆分 — 新品测算页完成

### 最终方案：pyside6-uic 预编译
- 5 个面板 .ui 补全为标准 Qt Designer 格式（class/resources/connections）
- pyside6-uic 生成 5 个 Python UI 类到 ui/generated/
- 5 个面板 widget（ui/panels/calc_panels.py）通过 setupUi() 创建独立 C++ widget 树
- load_calculation_panel() 改为创建面板 widget（不再用 QUiLoader）
- tools/generate_calc_panels.py 重新生成脚本

### 根因
原 .ui 文件只是 widget XML 片段包上 <ui> 标签，缺少 class/resources/connections。
QUiLoader 在 Linux 下加载这种不完整 .ui 文件时，子控件生命周期错误，导致 segfault。
pyside6-uic 通过 setupUi() 创建完整 Qt widget 树，避免问题。
